# Personal Documentation & Notes

This directory contains personal documentation, learning materials, and analysis created while exploring the Strands Agents SDK. These files are separate from the official SDK source code.

## Directory Structure

### `guides/`
Integration and usage guides for SDK features.
- **bidi/** - Bidirectional streaming architecture deep-dives
- Conversation management, streaming/async patterns, hooks, protocol integration

### `notebooks/`
Jupyter notebooks for hands-on exploration.
- **examples/** - Standalone Python scripts demonstrating concepts
- Token limits, MCP features

### `feature-notes/`
Feature analyses, comparisons, and release notes.
- Post-1.0 feature breakdowns (Top 5, 6-10, 11-15)
- SDK vs raw implementation comparisons
- Timeline and capability overviews

### `presentations/`
Presentation-ready materials for demos and talks.

### `reviews/`
PR review analysis and deep-dives.
- **pr-1305-cache-analysis/** - Prompt caching analysis with notebooks and test scripts

### `Slack/`
Q&A documentation from Slack discussions.
- Integration troubleshooting (e.g., Langfuse)

---

*These notes are for personal reference and learning. For official SDK documentation, see the root `docs/` directory or the [Strands documentation](https://strandsagents.com).*
